# Rishabh Gautam Portfolio

A simple personal portfolio website built with HTML and CSS. It showcases professional experience, research work, projects, and contact details for Rishabh Gautam.

## Project Overview

This portfolio includes:

- A home page with a short introduction and experience highlights
- A contact page with email, phone, GitHub, and LinkedIn links
- Responsive layout for desktop and mobile screens
- Clean styling with a modern dark header and light content sections

## Files

- `index.html` — homepage and profile overview
- `contact.html` — contact page
- `README.md` — project documentation

## How to View Locally

Since this is a static website, you can open it directly in a browser:

1. Open `index.html` in your browser, or
2. Use a local preview extension such as Live Server in VS Code

To view the contact page, open `contact.html`.

## Customization

You can update the following in the HTML files:

- Personal name and introduction text
- Experience and project details
- Social links
- Email and phone number
- Styling colors and layout values in the internal `<style>` blocks

## Notes

There is no dependency installation or build step required for this project. It works as a plain static HTML/CSS website.
